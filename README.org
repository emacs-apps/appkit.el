#+title: appkit.el
#+options: toc:nil num:nil

Repository: [[https://github.com/emacs-apps/appkit.el][emacs-apps/appkit.el]].

Appkit is the runtime and presentation library behind the Emacs clients in
this repository (QQ, Disco, Slackit, Zulip, Matrix, Chirp, Bili, Verse and
others).  It owns application and buffer lifecycle, the order in which state
changes and presentation commit, asynchronous work, and reusable buffer UI:
projections, chat buffers, composers, markup and media.

Clients own their protocol: data models, transport, validation, persistence,
identity, faces and branding.  Appkit defines no channel, message or account
model.

* Requirements

- Emacs 32.0 or newer, graphical for images and video
- ~plz~ 0.8+
- ~video.el~ 0.1+ with its native module built
- Optional: Evil (bindings load after it), the Markdown Tree-sitter grammars
  (Markdown codec), Respond (default translation backend)

~(require 'appkit)~ loads every module.  Appkit keeps no compatibility aliases;
use the public ~appkit-*~ names directly.

#+begin_src emacs-lisp
(use-package appkit
  :straight (:host github :repo "emacs-apps/appkit.el"))
#+end_src

Inside the monorepo, packages and their load paths are registered in
[[file:../../emacs-dev/dev-registry.el][emacs-dev/dev-registry.el]].

* Development

Tests live in ~test/~.  Run them in an Emacs daemon with
[[file:../../emacs-dev/dev.el][emacs-dev/dev.el]] loaded, preferably a fresh
~emacs -Q~ daemon whose ~load-path~ comes from the package registry:

#+begin_src emacs-lisp
(dev-run-test-files
 (directory-files "~/Projects/dev-monorepo/appkit-apps/appkit.el/test"
                  t "-test\\.el\\'"))
#+end_src

~dev-run-test-files~ runs only the tests declared in those files and returns
counts plus unexpected results.  Wrap loading in ~dev-with-source-loads~ (or set
~load-prefer-newer~) so stale ~.elc~ files in the tree cannot hide source edits.

Canvas geometry, real playback and touch input need a graphical frame.  Tests
that skip in batch prove nothing about them.  Smoke-test those paths in a
running client.
