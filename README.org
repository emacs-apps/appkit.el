* What it is

Appkit is a protocol-neutral runtime for stateful Emacs clients.  Its vNext
control plane owns serialized App and Surface models, finite keyed Effects,
generated-buffer lifecycle, and presentation commit ordering.  Reusable
projection, compose, chat, media, markup, and geometry modules remain
presentation mechanisms beneath that runtime.  Client packages own protocol
types, transport adapters, domain transitions, and branding.

Current consumers include ~disco.el~, ~emacs-qq~, ~emacs-slackit~,
~emacs-zulip~, and ~chirp~.  Appkit does not define Discord, QQ, Slack,
channel, or message models.

* Install

#+begin_src emacs-lisp
;; straight.el
(use-package appkit
  :straight (:host github :repo "emacs-im/appkit.el"))

;; package-vc (Emacs 29+)
(use-package appkit
  :vc (:url "https://github.com/emacs-im/appkit.el"))
#+end_src

* Requirements

- Emacs 32.0+
- ~plz~ 0.8+
- ~video.el~ 0.1+ with its native module built

* Depend

Sibling packages load it as a local file dependency:

#+begin_src emacs-lisp
(depends-on "appkit" :file "../appkit.el")
#+end_src

No consumer compatibility aliases are provided.  Use the public
~appkit-*-~ namespaces directly.

* Development

Eask owns package activation and load paths:

#+begin_src sh
eask recompile
scripts/eask-ert-brief test/*.el
#+end_src

The brief runner recompiles immediately before testing and forwards
its arguments to ~eask test ert~.
